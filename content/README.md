# BodhAI Content Repository

Curriculum, knowledge graph definitions, and diagnostic item banks for Classes 6 to 10 in India.

## Organization

- `curriculum/`: Formal subject and competency mappings for NCERT/State boards.
- `items/`: Question items, assessment prompts, rubrics, and diagnostic distractors.

## Class Scope

- Class 6 (Middle School)
- Class 7 (Middle School)
- Class 8 (Middle School)
- Class 9 (Secondary)
- Class 10 (Secondary / Board Preparation)
